# CineTrack

CineTrack is an iOS application currently under development.

Users can:
- Track watched movies and TV episodes.
- Record viewing dates, ratings, and notes.
- View separate movie and TV viewing statistics.
- Create watchlists and track annual goals.
- Earn XP and customize an avatar.

The app plans to use TMDB for movie and TV information,
posters, genres, runtimes, and season and episode details.

This repository contains the project introduction only.
The application has not yet been published.
